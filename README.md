# 📊 Анализ рынка IT-вакансий Санкт-Петербурга (HeadHunter API)

## 📝 О проекте
Этот проект — мини-исследование рынка труда в сфере IT в Санкт-Петербурге. Данные были собраны через публичный API HeadHunter (hh.ru) с использованием утилиты `curl` и обработаны с помощью `jq` и командной строки UNIX. 

**Цель:** Понять, какие компании ищут IT-специалистов, как распределяются вакансии по опыту и уровню зарплат, а также проверить гипотезу о востребованности Junior-специалистов.

## 🛠 Использованные инструменты
*   **Сбор данных:** `curl` (запросы к API HeadHunter)
*   **Обработка JSON:** `jq` (фильтрация, извлечение полей, конвертация в CSV)
*   **Анализ данных:** `awk`, `sort`, `uniq` (подсчет частот, сортировка, поиск медианы)

## 📂 Структура проекта
*   `fetch_it_spb.sh` — скрипт для сбора сырых данных.
*   `custom_filter.jq` — фильтр для конвертации JSON в CSV.
*   `it_spb.csv` — очищенный датасет с IT-вакансиями (100 записей).
*   `junior_spb.json` — сырые данные по Junior-вакансиям.
*   `dev_spb.json` — сырые данные по запросу "разработчик".

## 🔍 Ключевые инсайты (Результаты)

### 1. География IT-рынка
Санкт-Петербург — второй по величине IT-хаб России после Москвы. Однако, если мы посмотрим на конкретные компании, то их распределение неравномерно.
*   **Газпром нефть** имеет **103 вакансии в Москве**, **50 в Питере** и **0 в Тюмени**. Это доказывает, что их главный IT-офис находится в столице, а не в регионе добычи.
*   **Яндекс.Еда** в Питере — это логистический хаб. В топе их вакансий — курьеры, велокурьеры и менеджеры по найму. Разработчиков под брендом "Еды" в СПб не ищут.

### 2. Кто ищет разработчиков?
По запросу "разработчик" в СПб в топ выбиваются:
*   Аутсорсинговые и консалтинговые компании (Aston, Рекруто).
*   Крупные корпорации (Сбер, Газпром информ).
*   Компании из других регионов, предлагающие удаленку (Алабуга).

### 3. Топ-10 компаний по количеству IT-вакансий (из выборки)
1.  Газпром нефть (4)
2.  Рекруто (2)
3.  АйТи-Солюшн (2)
4.  BI Consult (2)
5.  Aston (2)

### 4. Анализ зарплат
*   Многие компании (особенно крупные корпорации) **не указывают зарплату** в вакансиях, предпочитая обсуждать её на собеседовании. Из 100 вакансий зарплата была указана только в ~40% случаев.
*   Средняя зарплата (от) для IT-специалистов в СПб (по нашим данным) составляет около **60 000 – 80 000 рублей**.
*   Медианная зарплата (более честный показатель) находится в районе **70 000 рублей**.

### 5. Нужны ли Junior'ы? (Больной вопрос)
Да, но рынок для них специфичен.
*   Всего в СПб найдено **215 вакансий** для Junior/без опыта.
*   **Только 82 из них** указывают зарплату.
*   **Кто их ищет:** В основном это не продуктовые IT-компании, а:
    *   **Digital-агентства** (Junior Media Buyers — закупка рекламы, зарплаты до 100к).
    *   **Интеграторы 1С и CRM** (Первый Бит, Айти Ворлд).
    *   **Крупные корпорации** на позиции стажеров (зарплаты 20-40к).
*   **Лазейка для джунов:** Направления **DevOps** и **1С-разработка** предлагают джунам зарплаты в диапазоне 80 000 – 100 000 рублей. Это значительно выше, чем классическая "Python-разработка для начинающих".

## 🏁 Вывод
Рынок IT в Санкт-Петербурге остается высококонкурентным. Для успешного старта карьеры Junior-специалисту стоит либо идти в смежные области (DevOps, QA, 1С, Digital), где меньше конкуренции и выше стартовые зарплаты, либо проходить жесткий отбор на стажировки в крупные корпорации.
